# Student Management System
A Student Management System developed using Java and Spring Boot to manage student records through REST APIs.

## Technologies Used
1 Java
2 Spring Boot
3 Spring Data JPA
4 Hibernate
5 MySQL
6 Maven
7 REST API

## Features
a. Create student records
b. Retrieve student records
c. Update student information
d. Delete student records
e. Store student data in a MySQL database

## Project Architecture
The project follows a layered architecture:
-Controller: Handles HTTP requests.
-Service: Contains business logic.
-Repository: Communicates with the database.
-Entity: Represents student data.

## Database
MySQL is used to store student information.

## Learning Outcomes
* Developed REST APIs using Spring Boot.
* Connected a Spring Boot application to MySQL.
* Practised layered application architecture.
* Implemented CRUD operations.
